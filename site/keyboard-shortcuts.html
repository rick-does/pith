Keyboard Shortcuts

Hierarchy navigation and reordering

These shortcuts work when you have selected a file chip in the hierarchy (click a chip to select it).

Key Action
↑ Move the selected file up
↓ Move the selected file down
→ Nest under the file above (make it a child)
← Unnest (move up one level)

Movement crosses level boundaries — press ↑ at the top of a group to move the file above its parent.

Unlinked file shortcuts

These shortcuts work when you have selected one or more files in the Unlinked pane.

Key Action
↑ Move the selected file up in the Unlinked list
↓ Move the selected file down in the Unlinked list
← Move all selected files into the hierarchy

Using ↑ or ↓ in the Unlinked pane automatically switches the sort order to Custom.

Search

Key Action
Ctrl+F / Cmd+F Open full-text search

Editor shortcuts

Key Action
Ctrl+S / Cmd+S Save the current file

Vi mode commands

When vi mode is enabled, the following ex commands are available in addition to standard vi keybindings:

Command Action
:w Save the current file
:x Save the current file and close the editor

Renaming

Action How
Rename a file chip Double-click the chip label
Rename from the editor Double-click the filename in the editor toolbar
Rename a project Double-click the project chip to open project notes, then double-click the project name in the notes editor toolbar
